プライバシーポリシー

本ポリシーは、富田悠斗が運用するGoogle Workspace業務連携ツール（OAuth同意画面の表示名「Claude Code」）によるGoogleユーザーデータの取り扱いを説明します。

1. 取得する情報と利用目的

利用者が許可した権限の範囲で、Googleアカウントの識別情報、認証トークン、指示された業務に必要なファイル・表・文書・メール・予定・チャット・連絡先・タスク・フォーム・スクリプト等の情報を取得・処理します。利用目的は、業務資料の作成・更新、レポート作業、連絡の確認・下書き、予定やタスクの整理など、利用者が指示した機能の提供です。

2. AIサービス等へのデータの送信

連携ツールの実行結果は、利用者が接続して使用するAIアシスタントに渡される場合があります。Codex・ChatGPTを使用する場合はOpenAI、Claudeを使用する場合はAnthropicのサービスで、業務の指示や取得結果が処理される場合があります。実行する業務に必要なデータに限定し、Google APIで取得した情報を汎用AIモデルの学習・改善に使用する設定・運用では利用しません。認証トークンやアプリの秘密鍵をAIへの業務入力や公開ページへ含めない運用を行います。

3. 利用の制限

Googleユーザーデータを販売したり、広告の配信・ターゲティング目的で利用したりしません。機能の提供、安全確保、法令対応等、Googleのポリシーで許容される場合を除き、第三者への転送や人による閲覧を行いません。

本ツールによるGoogle APIから受け取った情報の利用および他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

4. 保存と保護

Googleの認証情報は、運用者が管理するローカル環境の認証ファイルに保存します。認証情報と業務データへのアクセスを必要な範囲に限定し、外部サービスとの通信には暗号化された接続を使用します。業務の出力や作業記録は、必要に応じてローカル作業場、利用者のGoogle Workspace、指定された業務管理サービスに保存します。AIサービスに渡された情報の保存・処理には、使用するサービスの契約およびデータ設定も適用されます。

5. 利用停止と削除

利用者はGoogleアカウントの接続管理からアクセス権を取り消せます。取り消し後は新たなアクセスができなくなります。既に保存した認証情報、業務出力、作業記録、AIサービスの会話履歴等は自動で一括削除されないため、必要に応じて運用者がそれぞれの保存先で削除します。データの削除や取り扱いに関する問い合わせは下記窓口で受け付けます。
